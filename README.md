# JFLAP Formal Languages Practicals

This repository contains JFLAP models and diagram snapshots created while practicing concepts from Formal Languages and Automata Theory.

## How to use these files

- **`.jff` files** are editable JFLAP files. Open them with JFLAP to inspect states, transitions, productions, or machine behavior.
- **Diagram snapshots** (`.jff.jpg` files) provide visual references for the corresponding practicals.
- When reviewing a model, run representative accepted and rejected inputs in JFLAP to confirm its behavior.
